# 10 Founder Communities Worth Being In

Every link below was checked today (2026-08-17) and resolves to a real, active community. What I could **not** do: log into each one and pull "one recent gig" — Slack/Discord/Telegram render via JS and require membership, so there's no way to read channel history from the outside without joining. That part of the ask needs you, once, per community — it's usually a 2-minute skim after joining. Where a community's hiring channel name is a documented convention, it's noted; where it isn't public, "check after joining" is the honest answer.

Discord invite links rot (servers regenerate them). If one below 404s, search `"<community name>" discord invite` — takes 10 seconds.

## Why no fabricated "recent gig" per row

I looked hard for a way around this (tried Reddit's public JSON API directly via curl, tried fetching old.reddit.com, tried rendering Discord/Slack pages) — all blocked, either by the platform (Reddit returned an explicit 403 "blocked due to network policy") or because the content simply isn't served without an authenticated session (Slack/Discord). Rather than invent a plausible-sounding post and pass it off as real, here's the actual real substitute: [04-fresh-hiring-posts.md](04-fresh-hiring-posts.md) has 5 verified, dated, linkable posts pulled from Hacker News's public API — same intent, real data, working links.

## Fastest way to make these 10 pay off

Don't lurk. In each one within the first week: (1) post a one-line "who I am / what I do" intro if the community has an intros channel, (2) search "hiring" and "looking for" and reply to 2–3 relevant threads, (3) if there's a jobs channel, post your own availability once using the template in [templates/community-availability-post.md](templates/community-availability-post.md).
