# Wellfound / Newly-Funded Founder Pitch (standalone, ~50 words)

Context and 3 pre-filled examples: [../05-wellfound-startups.md](../05-wellfound-startups.md). Send via Wellfound's own message/apply flow, or the founder's public LinkedIn/X. There's no legitimate way to get a scraped personal email, and platform-native contact usually gets read faster anyway.

## Blank template
```
Congrats on [the raise / coming out of stealth]. [One line connecting what they're building to your actual background: infra, backend, cloud, data pipelines.] I've spent 20 years doing exactly this kind of work (AWS, Python/TypeScript/Go, cloud architecture). If early scaling means you need extra hands before the team's fully staffed, happy to help. Remote, contract, glad to work [their city/US] hours, can start fast.
```

## Variant: reacting to a specific hiring post instead of a funding announcement
```
Saw you're hiring for [role]. Even if the search is for full-time, wanted to flag I'm around for contract work covering similar ground ([1-2 specific skills from their post]). Based abroad but flexible on timezone, happy to work your hours. Could be a good stopgap while you run the full-time search, or work longer-term if that ends up fitting better.
```
