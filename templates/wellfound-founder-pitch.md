# Wellfound / Newly-Funded Founder Pitch (standalone, ~50 words)

Context and 3 pre-filled examples: [../05-wellfound-startups.md](../05-wellfound-startups.md). Send via Wellfound's own message/apply flow, or the founder's public LinkedIn/X — there's no legitimate way to get a scraped personal email, and platform-native contact usually gets read faster anyway.

## Blank template
```
Congrats on [the raise / emerging from stealth] — [one line connecting what they're building to your actual background: infra, backend, cloud, data pipelines]. I've spent 20 years on exactly that kind of work (AWS, Python/TypeScript/Go, cloud architecture). If early scaling means extra hands before the team's fully staffed, I'd love to help — remote, contract, can start fast.
```

## Variant: reacting to a specific hiring post instead of a funding announcement
```
Saw you're hiring for [role] — even if the search is for full-time, wanted to flag I'm available for contract work covering similar ground ([1–2 specific skills from their post]). Could be useful as a stopgap while you run the full-time search, or longer-term if that ends up working better for the team.
```
