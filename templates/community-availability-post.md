# Community Availability Post (standalone)

For posting once in a community's jobs/hiring channel (not a 1:1 DM). Referenced from [../01-founder-communities.md](../01-founder-communities.md).

```
👋 [Name] here, solutions architect / full-stack dev, AWS + Python + TypeScript + Go. Based in Armenia, open to contract and freelance work: cloud migrations, infra cleanup, backend builds, DevOps. Happy to share examples, feel free to DM.
```

## Slightly longer variant (for communities that welcome fuller intros)
```
👋 Hi all, I'm [Name]. Background's in solution architecture and full-stack dev: AWS (CDK, ECS, Lambda, EKS and the rest), Python, TypeScript/Node, Go, Kubernetes, Terraform. Been doing this for 20 years across startups, scale-ups, and enterprises, most recently running my own consultancy out of Armenia.

Currently taking on contract and freelance work: cloud migrations, architecture reviews, backend builds, DevOps and infra cleanup. Happy to share past work or jump on a quick call if anyone here (or anyone you know) could use an extra senior hand.
```

Post once per community, don't repost weekly, it reads as spam. Re-post only if the community explicitly has a recurring "who's available" thread (some do, weekly or monthly).
