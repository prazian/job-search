# Community Availability Post (standalone)

For posting once in a community's jobs/hiring channel (not a 1:1 DM). Referenced from [../01-founder-communities.md](../01-founder-communities.md).

```
👋 [Name] here — solution architect / full-stack engineer, AWS + Python + TypeScript + Go, 20 years combined experience (ex-Denmark, now based in Armenia). Open to contract/freelance work: cloud migrations, infra cleanup, backend builds, DevOps. Happy to share examples — feel free to DM.
```

## Slightly longer variant (for communities that welcome fuller intros)
```
👋 Hi all — [Name]. Background is solution architecture and full-stack development: AWS (deep — CDK, ECS, Lambda, EKS and the rest), Python, TypeScript/Node, Go, Kubernetes, Terraform. 20 years combined experience across startups, scale-ups, and enterprises, most recently running an independent consultancy out of Armenia.

Currently taking on contract/freelance work — cloud migrations, architecture reviews, backend builds, DevOps/infra cleanup. Happy to share past work or hop on a quick call if anyone here (or anyone you know) could use an extra senior hand. 
```

Post once per community — don't repost weekly, it reads as spam. Re-post only if the community explicitly has a recurring "who's available" thread (some do, weekly or monthly).
