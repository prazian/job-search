# LinkedIn 3-Part Outreach Sequence (standalone)

Fill in `[brackets]`. Send message 1 same-day, message 2 on day 3–4 (only if no reply), message 3 on day 7–10 (only if still no reply). Full context/rationale: [../02-linkedin-playbook.md](../02-linkedin-playbook.md).

## Message 1 — same day
```
Hi [Name] — saw your post about [specific thing they said].

I'm a solution architect / full-stack engineer (AWS, Python, TypeScript, Go — 20 years combined experience), currently taking on contract work. [One line tying your background to their specific problem.]

Happy to send 2 quick examples of similar work if useful — no pressure either way. Is this still open?
```

## Message 2 — day 3–4
```
Following up in case this got buried — no worries if the timing's off or it's filled.

One more thing that might be relevant: [specific useful link/observation/case study]. 

Either way, if you need backup capacity down the line, happy to stay in touch.
```

## Message 3 — day 7–10 (final)
```
Last note from me on this — didn't want to keep nudging.

If it's still open, I'm around and can usually start within a few days. If not, no hard feelings at all — feel free to keep me in mind if something similar comes up. Good luck with [specific thing they're building]!
```

## Short variant (for people who reply fast / when you want to be terser)
```
Hi [Name] — [specific reference to their post]. I do exactly this (AWS/Python/TypeScript/Go, contract, remote). Worth a quick chat?
```
