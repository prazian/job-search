# OSS Maintainer Pitch (standalone, generic)

Rule: comment on a **specific, real, currently-open issue** — never a generic "I'd love to contribute" DM. Do the work first, mention availability second. Context: [../03-opensource-targets.md](../03-opensource-targets.md).

## Claiming an issue + soft-mentioning availability
```
Happy to pick this up — I've done [specific relevant prior work, one line] on production systems. If it's still open I can have a PR up within a few days.

[Optional, only if it fits naturally:] If the team's ever open to ongoing contract help beyond this one issue, happy to talk — background's [AWS / Terraform / Go / TypeScript / cloud architecture], available now.
```

## Discussions tab / Discord #contributing channel (broader ask, not tied to one issue)
```
Long-time lurker, first-time poster — really like what you've built here. I have a cloud infra/backend background (AWS, Go, TypeScript, Python) and I'm looking to contribute more seriously, including potentially on a paid basis if the project or its sponsors ever need extra hands. Is that a conversation worth having, or is the team purely volunteer-driven right now?
```

## After a merged PR (the actual highest-leverage moment)
```
Glad that landed cleanly. If you or anyone in your network ever needs contract help on the infra/DevOps side — this is basically what I do full-time — happy to be one call away.
```
