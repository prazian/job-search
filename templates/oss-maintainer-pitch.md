# OSS Maintainer Pitch (standalone, generic)

Rule: comment on a **specific, real, currently-open issue**, never a generic "I'd love to contribute" DM. Do the work first, mention availability second. Context: [../03-opensource-targets.md](../03-opensource-targets.md).

## Claiming an issue + soft-mentioning availability
```
Happy to pick this up. I've done [specific relevant prior work, one line] on production systems before, so this is familiar territory. If it's still open I can have a PR up in a few days.

[Optional, only if it fits naturally:] Also, if the team's ever open to ongoing contract help beyond this one issue, happy to chat. Background's [AWS / Terraform / Go / TypeScript / cloud architecture], available now.
```

## Discussions tab / Discord #contributing channel (broader ask, not tied to one issue)
```
Long-time lurker, first-time poster here. Really like what you've built. I've got a cloud infra/backend background (AWS, Go, TypeScript, Python) and I'm looking to get more involved, maybe even on a paid basis if the project or its sponsors ever need extra hands. Worth a conversation, or is the team purely volunteer-run right now?
```

## After a merged PR (the actual highest-leverage moment)
```
Glad that one landed clean. If you or anyone in your network ever needs contract help on the infra/DevOps side, that's basically what I do full time. Happy to be one call away.
```
